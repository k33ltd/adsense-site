How to Use

  1. Add each application when you submit — card, bank, bonus, spend requirement, deadline.
  2. Update spend monthly (or weekly) — the progress bar shows % complete and daily pace needed.
  3. Mark "Bonus Posted" when points hit your account — moves to Completed.
  4. Export CSV for backup or spreadsheet analysis.

Status Meanings

  • Tracking — Application submitted, working on spend
  • Pending — Spend met, waiting for bonus to post
  • Complete — Bonus received ✓
  • Missed — Deadline passed without meeting spend

Pro Tips

  • Set deadline = approval date + months stated in terms (usually 3 months)
  • Green progress = on track. Yellow = need to accelerate. Red = at risk.
  • Use "Last 4 Digits" to distinguish multiple same-card applications
  • CSV export includes all fields for tax records or churning logs
