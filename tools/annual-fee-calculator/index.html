How the Math Works

For each card, we calculate:

Net Annual Value = (Spend × Earn Rate × Point Value) + Statement Credits + Perk Value − Annual Fee
  • Point valuations: Chase UR 1.5¢ (Reserve) / 1.25¢ (Preferred), Amex MR 1¢ (Plat) / 0.6¢ (Gold), CapOne 1¢, Bilt 1¢
  • Credits counted: Only automatic/universal credits (e.g., $300 travel, $120 dining, $100 airline). Targeted offers excluded.
  • Perk value: Lounge access = $200/yr, hotel status = $150/yr, free night = $200/yr (conservative).
  • Caps enforced: Amex Gold groceries $25K/yr, Chase Sapphire dining $25K/quarter (portal), etc.
